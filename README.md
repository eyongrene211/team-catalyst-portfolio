# Team Catalyst - Personal Portfolio Website

## 📖 About The Project
This is a collaborative, static personal portfolio website built by **Team Catalyst**. The project showcases our ability to work as a development team, utilizing modern front-end technologies. The site features a responsive layout, a dark/light mode toggle, smooth scrolling, animated sections, and a contact form – all built with pure HTML, CSS (Tailwind), and vanilla JavaScript.

**Key Features:**
- Responsive design (mobile-first) using Tailwind CSS grid and utilities
- Dark/light mode toggle with vanilla JavaScript
- Smooth scrolling and animated sections
- Semantic HTML5 structure
- Contact form with basic validation

---

## 🛠️ Built With
- **HTML5** – page structure
- **Tailwind CSS** – styling and responsiveness (offline mode)
- **Vanilla JavaScript** – interactivity (theme toggle, mobile menu, form validation, scroll effects)

## 🚀 Getting Started

### Prerequisites
- A web browser
- A code editor (VS Code recommended)
- Git installed
- Node.js and npm (for Tailwind CSS build)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/eyongrene211/team-catalyst-portfolio.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd team-catalyst-portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Build Tailwind CSS**
   ```bash
   npm run tailwind-build
   ```
   > Keep this running in a terminal while you work — it watches for changes.

5. **Open `index.html`** in your browser (double-click or use Live Server).
